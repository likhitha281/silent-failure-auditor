What formats are supported?
Three shapes are recognized automatically:
  • Generic event list — an array of {tool, args, output, textAfter} objects. Easiest to produce from any custom wrapper.
  • Anthropic/OpenAI-style transcript — an object with a messages array containing tool_use / tool_result content blocks.
  • Codex CLI rollout — paste the raw contents of a rollout-*.jsonl file from ~/.codex/sessions/. Lines are {timestamp, type, payload}, with tool calls under type:"response_item" linked by payload.call_id.
[
  {"tool":"run_tests","args":"pytest tests/","output":"1 failed, 4 passed\nFAILED test_x","textAfter":"All tests pass now."},
  {"tool":"edit_file","args":"src/app.py","output":"12 lines changed","textAfter":"Updated the handler."}
]
